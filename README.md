# Quilombotech

Grupo Gambiarra

## Objetivo do Projeto

Desenvolver uma plataforma de mapeamento georreferenciado que dê visibilidade aos quilombos remanescentes da Bahia, democratizando o acesso às suas histórias e transformando-os em centros de memória virtual da resistência afro-brasileira. Além disso, pretende-se expandir esse mapa por meio de uma metodologia ativa apoiada em visão computacional, permitindo o encadeamento dinâmico do fluxo de navegação e ampliando a imersão dos usuários na experiência.

## Como iniciar o projeto

Baixar repositório

> git clone https://github.com/Pedrobolfute/Quilombotech

Baixar node

> sudo apt install node

Baixar npm

> sudo apt install npm

OBS: Adquirir arquivo chave para comunicação com API

- Pedir acesso aos colaboradores à chave da API do Firebase
  - pepenike-101@hotmail.com

> Colocar arquivo chave **firebase.json** dentro da pasta api

Entrar na pasta api e rodar comando npm install

> npm install

Iniciar servidor

> npm start
